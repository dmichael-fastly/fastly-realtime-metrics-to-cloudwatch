# Fastly Real-Time Metrics to CloudWatch

See `README.md` for architecture (serverless polling loop: EventBridge → Lambda → Fastly Real-Time API → CloudWatch), configuration, cost analysis, and getting-started docs.

## Commands
- `.venv/bin/pytest src/test_lambda_function.py` — run tests. Python 3.12 venv at `.venv/`; `pytest.ini` sets `pythonpath` and asyncio auto mode, so run from the repo root.
- `terraform fmt -recursive` and `terraform validate` — run from `terraform/`.
- `./deploy.sh` (or `-y` to auto-approve) — zips `src/` + `metrics.ini` and runs `terraform apply` against real AWS. High-impact: requires explicit human approval every time.
- `./teardown.sh` — destroys all AWS resources. Never run without explicit approval.

## Key files
- `src/lambda_function.py` — polling loop, `aiohttp` fetches, sparse-data parsing, `PutMetricData` batching.
- `src/test_lambda_function.py` — pytest suite (`pytest-asyncio`, `unittest.mock`) covering parsing, flattening, sparse data, cold starts.
- `metrics.ini` — manifest of which Fastly metrics get pushed (controls CloudWatch storage cost). `metrics.ini.example` is the template.
- `terraform/dashboard.tf` — Edge dashboard (stacked charts, hit-ratio metric math).
- `terraform/origin_dashboard.tf` — Origin dashboard (12-bucket latency histograms).
- `terraform/alarms.tf` — per-service alarms: 5xx spikes, zero traffic, high latency.

## Conventions and gotchas
- **Sparse data model**: Fastly's real-time API omits a metric key entirely when its value is zero in that 1-second bucket. All parsing must treat a missing key as 0, never as an error.
- **Metric name casing**: `metrics.ini` uses Fastly's snake_case metric ids; the Lambda converts them to PascalCase before pushing. Terraform dashboards and alarms must reference the exact PascalCase CloudWatch names — a casing mismatch renders an empty chart with no error.
- **CloudWatch namespaces**: `Fastly/RealTime` (edge) and `Fastly/OriginInspector` (origin).
- **Secrets**: the Fastly API token lives in `terraform/terraform.tfvars` (gitignored) and AWS Secrets Manager at runtime. Never hardcode, log, or commit tokens.
- **Build artifacts**: `package/` and `lambda.zip` are generated by `deploy.sh` — never edit them by hand.
